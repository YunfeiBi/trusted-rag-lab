# 知序——高校科研团队知识管理与协作平台

重庆邮电大学软件工程硕士研究生《软件体系结构》课程小组项目。

课程汇报题目：**面向高校科研团队的知识管理与协作平台：软件体系结构设计与评估**。

知序面向实验室与科研项目组，用团队审批组织师生、用项目权限划分资料边界，提供版本化资料管理、证据检索和RAG引用问答。“协作”指审批、权限、通讯录及资料共享，不包含共同编辑、即时聊天或完整科研项目进度管理。仓库技术标识 `trusted-rag-lab` 保留。

## 当前状态

目标汇报时间为2026-11-20左右，最终本机展示。七个独立板块覆盖团队与项目、资料与版本、证据检索、知识问答、处理任务、评测及运行审计。已支持默认100MiB可配置流式上传、授权密码PDF本机解密、异步入库与引用原文。评测中心支持人工样例和单题三配置检索对比，正式人工验收与30题质量评测未完成；引用匹配不代表语义正确。

支持中文用户名注册、教师/学生身份、团队入组审批及QQ通讯录。只有本机管理员确认身份的教师能创建团队，学生不能创建；批准入组后可访问团队公共库，内部项目仍需单独授权。已有账号可在个人资料补填身份与邮箱，邮箱尚未验证。

## 技术方向

- 前端：Vue 3 + Vite，hash页面导航。
- 后端：Python 与 FastAPI，采用模块化后端。
- 数据：PostgreSQL 与 pgvector。
- 文档处理：独立 Worker。
- 运行：本机原生PostgreSQL及前后端、Worker启动脚本；Docker Compose保留为可选方向，未完成容器化验收。

2026-11-02 起，用户决定负责全部开发，AI 助手辅助设计、实现与验证；其他成员实际参与方式待确认。当前安排以开发协作台账为准，原六人开发分工保留为历史方案，课程贡献及 AI 参与均按事实说明。

## AI 参与

选题讨论、初步架构、分工和开发流程文档，以及仓库初始化材料，使用了本聊天 AI 助手辅助生成和修改。成员须复核采纳内容，持续记录后续 AI 使用与人工核验，真实说明个人贡献。实际模型未知时不猜测。

模型密钥、本地原始资料和运行数据不得提交到仓库。当前为私有仓库，未自动邀请协作者。

自动验证与正式质量评测不同。PDF摘录空白兼容修复后112项隔离回归、前端构建及浏览器检查通过。此前生成检查曾返回503，最新获授权单次诊断已返回结构化回答；不代表持续可用或答案语义正确。故障与修复见[PDF问答排查记录](docs/PDF问答摘录校验修复.md)。
