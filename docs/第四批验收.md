# 第四批验收：独立页面与引用问答

日期：2026-11-02。开发及下述自动验证由AI辅助完成，用户尚未进行本批人工验收。其他组员没有在此登记为已参与开发。

## 本批交付

- 项目、资料、检索和问答四个独立页面；侧栏切换专属内容，地址、前进/后退、项目上下文和手机导航一致。
- `POST /api/questions` 复用授权检索，生成带编号引用的事实段落，严格结构/编号/原文摘录检查；证据不足、生成故障和无效引用明确反馈。
- `GET /api/questions` 与 `GET /api/questions/{id}` 提供本人私有历史；新迁移 `0003_questions`。
- 点击引用查看原文并高亮来源位置；显示模型、提示版本、耗时和追踪编号。
- 生成前后及历史读取时重新核对权限和当前版本；失效回答隐藏，失败草稿不存库。

## 本机启动

升级已有项目先停止项目服务，再迁移并启动；不要覆盖 `.env`。

```powershell
./scripts/stop-local.ps1
./.venv/Scripts/python.exe -m alembic upgrade head
./scripts/start-local.ps1
```

访问 http://127.0.0.1:5173 。账号信息只在本机 `.local/demo_accounts.json`，不要发到聊天或提交到Git。改模型配置需要重启后端与Worker。

## 请用户实际验收

1. 登录，点击左侧“资料与版本”，确认项目卡片与成员管理不再混在当前页面。检查其他三个入口及浏览器前进/后退。手机窗口使用顶部导航。
2. 选择名为“引用问答验收（合成资料）-…”的项目，在知识问答同意外发后询问“项目管理员能做哪些成员管理操作？”。确认答案和引用摘录一致，点击引用检查原文高亮。
3. 询问“本项目年度预算多少钱？”，检查依据不足提示。用自己的资料测试前先确认资料可被所配置外部服务处理。
4. 重新进入问答页，确认自己的记录可以打开。另一个成员无法读取他人的记录。
5. 通过资料页更新或撤回用于回答的资料，再回问答历史，确认旧回答提示依据变化。建议使用专门测试资料，避免影响需要保留的演示资料。
6. 人工核对答案是否真正由原文支持，将误答或交互问题反馈；引用匹配只是来源检查，不是正确率证明。
