## 可以操作的功能

- 管理员上传文本型PDF或UTF-8 Markdown，明确确认处理授权。
- 独立Worker解析、按位置分块、生成向量并建立全文索引。
- 资料列表自动更新任务阶段、尝试次数及失败原因。
- 上传同一资料新版本，成功后切换；失败继续使用原可用版本。
- 查看版本记录、鉴权原文、片段及页码或行范围；Markdown按纯文本展示。
- 失败任务手动重试、管理员撤下资料、取消未完成任务并阻止后续访问。

## 启动与停止

在项目根目录执行；已有旧进程时先停止：

```powershell
.\scripts\stop-local.ps1
.\.venv\Scripts\python.exe -m alembic upgrade head
.\scripts\start-local.ps1
```

现在启动脚本会启动后端、前端和独立Worker三个进程。访问 http://127.0.0.1:5173 ，账号仍见本机 `.local/demo_accounts.json`。迁移后数据库版本应为0002_documents。

Worker日志在 `.local/worker.err.log`，按任务ID及错误码追踪，不记录文档正文和模型密钥。需要手动检查单个任务时可用 `.\.venv\Scripts\python.exe -m backend.worker --once`；常规演示不必重复启动，因为启动脚本已有Worker。

## 建议人工检查

1. 用项目管理员登录，在项目资料库查看现有“合成资料”样例，打开“版本与原文”，检查版本和片段位置。
2. 准备公开或获授权的简短Markdown，上传前确认已配置模型服务可以处理该资料，勾选授权并上传。
3. 观察“等待处理 → 处理中 → 已就绪”，打开原文及片段，核对文字和行范围。
4. 点击“更新”，上传修改后的文件，观察新版本成功后“当前可用”版本递增；历史版本仍可通过明确入口查看。
5. 上传一个独立空白Markdown或不含文字的PDF，确认显示解析失败而非无期限等待；先前可用版本不受影响。
6. 使用普通成员登录：可查看所属项目资料，没有上传、重试、更新与撤下操作。
7. 对一份可丢弃的合成样例执行“撤下”，确认普通成员列表不再展示，原文与片段接口拒绝访问；该操作当前不支持恢复，请不要用重要资料验收。
8. 需要演示撤权时使用不属于项目的身份，或管理员撤销特定成员后重新访问。现有演示账号关系可能已人工调整，不假定demo_other永远是项目外人员。

自动脚本留下了少量明确标注的合成演示资料，重复运行可能产生多个样例或新版本；它们不是真实科研资料，不属于正式评测数据。测试未擅自恢复或撤销人工设置的成员关系。

回归与冒烟命令：

```powershell
.\.venv\Scripts\python.exe -m pytest -q --tb=short
.\.venv\Scripts\python.exe scripts/check_ingestion_live.py
.\.venv\Scripts\python.exe scripts/check_browser.py --ingestion
npm --prefix frontend run build
```

pytest使用隔离schema、临时目录和假向量服务；后两项需要本机三个服务运行，并会发送少量合成文本到已配置向量服务、产生少量调用费用，同时保留合成演示文件。`check_browser.py`不加`--ingestion`时不创建新的向量任务。

真实结果在 `.local/ingestion-live-check.json` 和 `.local/browser-check/`，均被Git忽略；源文件在 `storage/`，也不进入Git。本页记录的是自动验证，用户尚未逐项反馈人工通过。

## 限制与下一步

当前只能入库、管理和查看片段，还不能在页面提问或搜索。下一批完成授权范围内关键词与向量召回、融合、重排序，再接证据约束生成。未来检索必须同时过滤项目权限、文档有效状态、当前版本以及模型配置，不得把历史或撤下片段直接返回。

不支持OCR、加密PDF、复杂表格理解及生产级不可信解析隔离。撤下禁止访问但不会物理删除文件。具体状态、重试及资源上限见 [决策002](decisions/002-文档入库与版本发布.md)。
