# 个人资料与科研项目编辑

更新日期：2026-11-04。适用系统：知序——高校科研团队知识管理与协作平台。

## 个人资料

登录后点击桌面侧栏或手机顶部的“个人资料”，会打开弹窗，预填当前账号的显示名称、QQ邮箱和成员身份。用户名只读，教师确认仍由本机可信管理员执行，自行选择教师不获得确认资格。

修改后点击“保存个人资料”。QQ邮箱已被其他账号使用等错误在弹窗内提示，并保留输入供修改。保存过程中表单与关闭按钮禁用，避免重复提交。点击取消、右上角关闭、遮罩或按Esc可放弃尚未保存的输入。

弹窗支持键盘焦点约束、关闭后返回原按钮、背景滚动锁定及手机内滚动，表单不再插入当前业务页面。

## 科研项目

进入“团队与项目”，项目管理员可点击项目卡片右下角“编辑”，也可在选中项目的成员区域点击“编辑项目”。弹窗预填所点击项目的名称和说明，不会把另一个当前项目的内容误当作编辑对象。

项目名称必填，最多100字符；说明最多2000字符，可清空。成功后卡片和当前项目名称同步更新，项目ID、成员授权与资料不变；取消不提交，错误在弹窗内显示。

普通项目成员可以查看资料和通讯录，不显示编辑入口，后端也拒绝其修改。教师、团队管理员身份不会自动获得内部项目编辑权限。团队公共库由团队设置维护，不能用普通项目编辑接口修改。
