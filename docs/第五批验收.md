# 第五批验收：任务恢复与运行诊断

日期：2026-11-03。AI辅助完成实现、测试和文档，自动验证通过，待用户人工验收；不新增其他成员的实际开发贡献记录。

## 可操作成果

1. Worker遇数据库异常进入有上限的退避重连，连接恢复后继续轮询；处理事务结果不确定时通过既有租约恢复，避免把基础设施故障错误登记为业务失败。
2. 资料页显示最近90秒Worker心跳和当前项目队列；任务显示自动重试时间、最大次数及处理中租约期限。
3. 通过迁移0004保存心跳；诊断接口只允许当前项目成员访问，队列统计限定当前项目。
4. 入库日志增加解析、向量、发布及总耗时；数据库故障日志只记录异常类型与重连间隔。资料页错误显示追踪编号。
5. 数据库连接和池等待5秒；修正向量返回将布尔值误当索引的问题，以及快速切页后资料轮询可能残留的问题。

## 人工验收步骤

访问 http://127.0.0.1:5173 ，重新登录后进入“资料与版本”：

1. 确认出现入库服务心跳和本项目等待、处理中、失败任务数。切换项目确认队列范围随项目改变。
2. 在手机宽度检查诊断文字和表格；表格可横向滚动，整页不应溢出。
3. 若需要检查任务恢复，优先运行隔离回归；不要为了演示破坏原始资料或强制停止数据库。自主手工测试前按 [故障排查与恢复](故障排查与恢复.md) 核对进程及数据影响。
4. 核对失败重试、旧版保留、引用依据变化等是否符合预期，反馈操作步骤和追踪编号。

用户未执行这些步骤前，保持“待人工验收”。心跳只说明近期活动，不证明具体任务成功、模型健康或系统可用率。
