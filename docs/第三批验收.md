# 第三批检索成果与人工验收

日期：2026-11-02。对应T04授权检索、T06搜索及原文定位、T07部分运行中权限变化与T08阶段耗时。当前可搜索证据，但还不能生成引用答案。

## 本批功能

- 关键词、纯向量、混合检索；混合模式支持重排序。
- 项目权限、有效资料、当前ready版本约束，向量模型不一致有提示。
- 结果展示出处、版本、位置、召回通道与排序分数，原文按页或行定位。
- 明确提示外部服务降级，返回阶段耗时、候选计数及追踪编号。
- 模型调用前后重新核验，检索期间撤权、退出、撤下或切版不会返回失效片段。
- 页面每5秒重验结果，打开原文单独鉴权；项目/身份切换清除旧组件状态。

## 启动与人工检查

```powershell
.\scripts\stop-local.ps1
.\scripts\start-local.ps1
```

数据库仍为0002_documents，无新迁移。访问 http://127.0.0.1:5173 ，账号密码仍在本机 `.local/demo_accounts.json`，不要发送到聊天或Git。

建议先使用“检索链路验收（合成资料）-随机后缀”项目，只有demo_admin是该新项目成员；用户原有项目和人工调整的关系未重置。

1. 登录demo_admin，选择上述合成项目，点击左侧“证据检索”或向下滚动到搜索区域。
2. 输入“项目资料通过什么方式控制访问权限？”，选择关键词模式，直接搜索；不需要外发授权，也不调用模型。
3. 切到纯向量模式，确认问题可以发往向量服务并勾选授权，再搜索，查看结果与实际模式。
4. 切到混合模式并启用重排序，确认候选也可送往重排序服务，再搜索。展开“查看本次检索过程”，检查两路计数、重排状态和阶段耗时。
5. 点击证据“查看原文”：Markdown显示段落行范围及高亮，PDF显示对应页；完整文件可下载，当前预览有行数和字符上限。
6. 使用不属于该合成项目的账号，确认项目不可见；不要假定demo_other对所有项目都是外部人员，因为此前成员关系已人工调整。
7. 需要测试撤下或切版时，选择合成资料；结果会在重验后移除失效片段，重新搜索应只使用有效版本。已下载到本机的文件不能被系统收回。
