# 决策006：文件资源边界、加密PDF与七板块

日期：2026-11-03。来源：用户明确要求支持大文件、授权密码PDF、七个板块及校徽。

## 文件处理

上传不再一次读取整个文件，应用以1MiB块写盘并累计大小；数据库中的校验值通过分块读取计算。整个multipart请求限制为配置文件上限加1MiB表单开销，既检查Content-Length，也限制实际接收字节。超限请求返回413并关闭解析器临时文件。框架仍会先将multipart文件暂存至系统临时文件；这不是浏览器分片上传、断点续传或零临时文件方案。

上传和PDF预处理不持有项目锁；文件准备成功后重新检查项目管理员权限，再短事务分配版本号、创建任务和审计。失败清理本次暂存文件，不修改已发布版本。进程崩溃或断电可能留下未被数据库引用的文件，目前没有自动孤儿文件回收器。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| MAX_UPLOAD_BYTES | 104857600 | 单文件100MiB；配置范围1KiB—1GiB |
| MAX_PDF_PAGES | 500 | PDF页数 |
| MAX_TEXT_CHARS | 500000 | 提取文本字符量；Markdown读取时提前截限 |
| MAX_CHUNKS | 1500 | 分块数量，避免无上限模型调用 |
| PARSE_TIMEOUT_SECONDS | 60 | 单次PDF预处理/解析子进程期限 |
| PROCESSING_TIMEOUT_SECONDS | 240 | 单次入库处理预算，默认小于300秒租约 |

配置写入本机 `.env` 后重启后端和Worker生效；已有 `.env` 未被覆盖。界面从已鉴权 `/api/file-limits` 获取当前值，运行页也显示限制。限制提高不是容量保证，文件字节大小不代表文字量或计算量。

## 密码的生命周期

加密PDF上传时使用可选的 `pdf_password` 表单字段。密码通过进程间管道传递给本机隔离预处理进程，不放入命令行、环境变量、数据库、审计或日志。不创建密码文件，也不发给向量服务；请求处理期间密码自然存在于浏览器与服务器内存，Python不提供密码字节可验证清零的保证。

没有密码、密码错误时返回明确提示。使用pypdf的crypto依赖支持AES PDF；文件解密和页数检查通过后，将解密副本替换本次暂存PDF，后续Worker无需密码即可处理。界面明确提示项目成员将可访问解密副本；用户必须有权上传并允许提取文字外发。原加密文件不作为已入库版本保留，版本文件大小与哈希对应解密副本。数字签名和某些复杂PDF结构不保证在重写后保真。

无论上传请求成功或失败，前端清空密码输入；切页也清空。不增加密码恢复、密码破解、永久保存密码或扫描件OCR功能。

PDF预处理、PDF/Markdown解析在可终止的子进程中执行；超时终止该子进程。Worker从路径解析PDF，不先将整个PDF读入bytes；Markdown按字符上限读取。向量分批调用前后检查总处理预算，HTTP调用超时不高于剩余预算。该预算覆盖正常解析/模型阶段，不是数据库锁等待、操作系统调度或所有上游慢速传输情况下的严格总墙钟上限；尚未设置操作系统级内存配额。

## 七板块的实际边界

| 页面 | 职责与接口 |
| --- | --- |
| 项目与成员 | 项目空间和项目内角色，沿用原接口 |
| 资料与版本 | 流式上传、密码预处理、原文与版本 |
| 证据检索 | 关键词、向量与混合召回，原文位置 |
| 知识问答 | 结构化引用回答与本人历史 |
| 处理任务中心 | 当前项目有效资料全部版本的任务，状态筛选、分页、失败重试 |
| 评测中心 | 人工标注样例、单题三配置检索对比、本人实验历史及JSON导出 |
| 运行与审计 | 心跳/队列/配置上限、管理员操作审计 |

校徽使用用户提供图片的原样副本，放在登录页学校标识、桌面侧栏品牌和移动身份区。未生成或修改校徽，不将其作为学校官方产品背书。侧栏七入口各自挂载独立组件，继续共享当前项目，手机导航换行显示。

## 评测与审计数据

新增 `evaluation_cases`、`evaluation_runs`、`audit_events`，迁移 `0005_centers`。当前共13张应用表，另有Alembic迁移表。

管理员创建评测样例，正例要求当前项目的有效标准片段；未人工确认的草稿禁止运行。成员可运行已确认样例，需额外同意向量/重排外发。固定Top-5、候选20、RRF k=60，对比纯向量、混合无重排、混合有重排；记录实际执行模式、降级状态、模型、耗时及命中片段ID。

指标为单题Recall@5、Hit与倒数排名；不可回答样例无正例，指标为不适用，不将空集匹配记为100%，也不等同拒答正确率。历史记录只对运行者可见；版本失效时隐藏旧结果。调用前后继续核对会话/权限/当前证据，变化时不保存。首版UI每次运行一题，样例列表最多200条，历史最近20条；支持单份资料前100片段的标注，至多20条标准证据。尚无样例编辑/删除、30题批量执行/汇总或答案语义评分工具，下一批补充。

审计只记录本功能上线后成功的项目创建、成员变更、资料版本上传/撤下、任务重试、评测样例/实验事件，和业务变更同事务提交。管理员查看当前项目审计；普通成员无此权限。不补造既有事件，不记录正文、问题、密码或原始请求体。它是应用层操作记录，尚不是防数据库管理员篡改的审计系统。
