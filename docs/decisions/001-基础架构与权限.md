# 基础架构与权限决策

日期：2026-11-02。状态：首批实现基线，待用户人工评审。

## 运行方式

Vue 前端与 FastAPI 模块化后端；本机 PostgreSQL/pgvector；后续文档 Worker 独立运行。数据库结构由 Alembic 升级，不在应用启动时自动建表。前端开发服务器将 `/api` 代理到后端，减少跨域配置和重复地址。

## 账户和角色

不做公开注册。本地初始化工具创建演示账号，随机密码保存到 Git 忽略的 `.local/demo_accounts.json`，不写入源码和日志，不输出到聊天。

账户无隐式全局管理员权限。创建项目者成为本项目管理员，成员关系角色为 `admin` 或 `member`。管理员可在自己项目内添加或更新成员、撤销成员，不能移除或降级最后一位管理员。操作期间锁定项目行，避免并发撤销最后管理员。

访问项目的非成员统一收到404，避免暴露项目存在；成员越权管理收到403。已撤销关系即时失效，每次请求查询当前成员关系；禁用账号的既有会话也不能继续访问。

## 登录会话

密码使用带随机盐的 PBKDF2-HMAC-SHA256 哈希，仅保存派生结果。随机 Bearer 会话令牌只返回客户端一次，数据库存 SHA256 摘要；默认8小时过期，可退出撤销。原型采用可撤销数据库会话，避免引入 JWT 签名与撤销列表；代价是每次请求查询会话。

前端令牌只保存在当前页面内存，刷新需重新登录，不持久化到 localStorage。服务默认只监听127.0.0.1；HTTPS、公开服务防爆破、密码重置及统一认证暂不属于本机原型范围，公网部署前需补充。

## 首批数据和接口

| 数据 | 核心字段 |
| --- | --- |
| users | UUID、唯一username、display_name、password_hash、is_active、created_at |
| sessions | token_hash、user_id、expires_at |
| projects | UUID、name、description、created_at |
| memberships | project_id与user_id联合主键、role，外键及角色约束 |

| 接口 | 规则 |
| --- | --- |
| POST /api/auth/login | JSON username/password，返回令牌与用户，不接受客户端指定user_id |
| GET /api/auth/me | 返回当前有效身份 |
| POST /api/auth/logout | 撤销当前令牌 |
| GET/POST /api/projects | 仅列出所属项目；已登录用户可创建项目并成为管理员 |
| GET /api/projects/{id} | 当前成员可见 |
| GET /api/projects/{id}/members | 本项目管理员可见 |
| PUT /api/projects/{id}/members/{user_id} | 管理员添加或更新已存在用户的项目角色 |
| DELETE /api/projects/{id}/members/{user_id} | 管理员撤销关系，保护最后管理员 |
| GET /api/users?username=... | 仅精确用户名查询且请求人至少管理一个项目，用于添加已有账号 |
| GET /api/health/live 与 /ready | 进程存活与数据库迁移就绪检查，失败不返回连接串 |

请求追踪 ID 由服务器产生，错误结构统一为 `error.code`、`error.message`、`trace_id`。日志只记录方法、路径、状态、耗时和追踪 ID，不记录令牌、密码、正文和连接串。文档、版本、任务与片段在后续迁移中扩展，证据始终包含document_id、version_id、chunk_id和原文位置。
