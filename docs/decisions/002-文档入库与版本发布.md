# 文档入库与版本发布

日期：2026-11-02。状态：已实现并自动验证，待人工验收。

## 数据与接口

新增 documents、document_versions、ingestion_tasks 和 chunks，数据库迁移为0002_documents。文档指向当前可用版本，版本保存文件摘要、序号、模型与片段数；一个版本对应一个处理任务。片段保存1024维向量、分词文本、生成的全文检索列和位置元数据。向量类型显式引用 public.vector，隔离测试schema仍不包含public搜索路径。

| 接口 | 权限与行为 |
| --- | --- |
| POST /api/documents | 项目管理员，multipart包含project_id、file、allow_external_processing；可选title |
| POST /api/documents/{id}/versions | 项目管理员，锁定项目与文档后分配递增序号 |
| GET /api/projects/{id}/documents | 当前成员；普通成员不返回撤下资料，管理员可见撤下元数据 |
| GET /api/documents/{id}/versions | 当前成员且资料未撤下，返回历史元数据及任务状态 |
| GET /api/tasks/{id} | 任务所属项目当前成员且资料未撤下 |
| POST /api/tasks/{id}/retry | 管理员，仅最新提交版本的失败任务可手动重试 |
| POST /api/documents/{id}/withdraw | 管理员，阻止原文及片段访问并取消未完成任务 |
| GET /api/documents/{id}/source | 当前成员且资料未撤下；可指定version_id，否则取当前可用版本 |
| GET /api/documents/{id}/chunks | 同上且版本ready；offset及limit分页，不返回向量正文 |

旧的ready版本可通过明确version_id追溯，不参与未来默认检索。指定版本必须属于请求的文档，不能拼接另一个文档的版本ID绕过权限。存储路径、文件摘要和令牌不进入资料API响应。

## 异步与一致性

```mermaid
flowchart LR
    Upload[校验权限与外发授权] --> File[保存UUID命名原文件]
    File --> Queue[事务创建版本和任务]
    Queue --> Claim[Worker原子领取及租约]
    Claim --> Parse[解析及位置分块]
    Parse --> Embed[分批向量化及续租]
    Embed --> Publish[事务写片段与全文索引]
    Publish --> Switch[切换最高成功版本]
```

领取采用行锁与SKIP LOCKED。租约300秒，处理期间按阶段和向量批次续租；失败或进程中断后可回收，最多自动尝试3次。超时旧Worker持有的旧令牌不能续租或发布。瞬时网络错误、429与部分服务端错误有限退避重试；内容解析错误直接失败，等待修正后上传新版本。

向量调用在数据库事务外执行。发布时先锁文档，再锁任务，确认租约、令牌和资料有效，然后在同一事务内替换该版本片段、标记ready并调整指针。片段ID由版本ID与序号确定，版本内序号有唯一约束，避免重复发布形成重复片段。

版本指针按成功版本号单调前进，而不是按完成时间覆盖：若v2先成功，稍后完成的v1不能覆盖v2；若v3失败而v2成功，v2仍可以生效。新版本未成功时原可用版本继续服务。任务失败不删除原可用版本。

撤下操作和发布使用相同文档先行的锁顺序；撤下取消任务并使租约失效，进行中的外部请求已发出的文字不能撤回，但返回后不能再发布索引。撤下是禁止访问，不是物理删除原文件、历史片段及历史版本。

## 输入、定位与成本范围

- 仅接受文本型PDF与UTF-8 Markdown，上传不超过20MB；PDF不超过200页，单页解压内容流检查限8MB。
- 提取文字不超过20万字符，最多1000片段；每片段最多800字符、重叠120字符，位置不跨PDF页面或Markdown段落。
- Markdown记录章节及段落行范围；长段落的多个片段可能共享行范围，不声称字符级定位。
- PDF通过pypdf提取现有文本；不做OCR，不支持加密文件，扫描件无文字时明确失败。
- 每批最多8个片段向量化，验证1024维、有限数值和非零输出，成功记录实际模型名。
- 中文分词和全文索引已生成；关键词/向量混合检索接口在下一批实现。

用户上传前必须明确勾选资料权限及向量服务处理授权。自动检查仅使用合成内容。原型有输入上限，但尚无容器级解析资源隔离、恶意PDF沙箱、病毒扫描或生产级费用配额，不作为公开不可信文件处理平台。

## 已知代价

API与文件存储不是一个跨资源事务。普通写入失败会清理对应UUID文件，但进程突停仍可能留下无引用文件，后续需设计受控清理。手动重发上传请求会产生新文档或版本，不承诺HTTP请求级幂等；幂等针对Worker任务和索引发布。自动重试从头处理，可能重复向量调用，不是逐片段断点恢复。

资料列表当前最多100条，历史版本列表暂未分页；原文流在请求时鉴权，已下载到客户端或已发送到外部服务的内容无法通过之后撤权收回。前端每3秒刷新并在访问失效时清除本页预览；默认不持久化授权令牌。
