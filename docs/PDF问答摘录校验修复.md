# PDF问答摘录校验修复

日期：2026-11-03。适用系统：知序。代码与文档由AI辅助完成，尚待用户重新提问和人工核对。

## 原因与表现

知识问答原有完整的检索、模型生成、校验与展示流程。用户的手册问题已有5条检索证据，历史错误码为`CITATION_VALIDATION_FAILED`，不是只有资料检索能力，也不是本次生成接口503。

用户明确授权后的一次诊断收到了5条结构化结论，其中4条摘录的非空白文字与原文一致，但模型省略了PDF排版换行/空格。旧实现将空白合并成单个空格，中文断行仍留下间隔，导致错误拒绝。任一引用失败时系统隐藏整份草稿，前端又把相同失败原因显示两遍。

诊断没有保存回答草稿，也没有在日志或本文记录手册正文和秘密。接口成功不能证明结论语义正确。

## 修复规则

- 比较时仅忽略Unicode空白，要求至少8个非空白字符，仍核对编号与连续字符序列。
- 不忽略标点，不接受改字、跳字或新增省略号，不使用模糊匹配。
- 匹配成功后按位置恢复原文真实摘录，包含原有排版空白，供点击原文核对。
- 生成仍由大模型综合检索证据逐项作答，服务端添加引用；证据不足或校验失败时不编造答案、不展示失败草稿。
- 区分未知证据、摘录过短、摘录不一致及模型自行添加标记等安全原因；提示不包含草稿内容。
- 前端去除重复警告，仅成功回答显示引用语义核对说明。提示版本为`grounded-claims-v2`。
