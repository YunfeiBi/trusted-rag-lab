# 第七批验收：中文注册、项目编辑与成员通讯录

日期：2026-11-03。按用户要求由AI辅助实现、验证和记录，待用户人工验收；不登记其他成员未发生的开发贡献。

## 实际交付

- 登录页可切换注册，支持中文、英文字母、数字和 `_.-` 用户名，长度1—64字符；输入先做NFKC规范化与首尾空白清理，登录及成员精确搜索采用相同规则。英文字母大小写仍区分。
- 注册要求唯一的 `@qq.com` 联系邮箱和8—128字符密码，浏览器二次确认密码。密码继续使用带随机盐的PBKDF2哈希；重复用户名/邮箱（包括并发注册）返回409，输入错误不回显密码。
- 注册成功返回登录页，不自动授予现有项目权限。新账号可以创建自己的项目，加入其他项目仍需管理员添加。
- 个人资料可修改显示名称与QQ邮箱，不修改登录用户名；已有账号QQ邮箱保持空值，不编造联系人，界面显示“未填写”。
- 项目管理员可以编辑名称、说明，记录项目修改审计；项目ID、成员与资料不变。PATCH支持只改名称，未提供说明时保留旧说明。普通成员403，未加入项目404。
- 同项目所有成员可查看通讯录，包括显示名称、用户名、QQ邮箱和角色；普通成员没有权限编辑项目或成员。手机端使用卡片方式展示，邮箱可点击为mailto链接。

## 数据与权限边界

迁移 `0006_accounts` 仅向 `app_users` 增加可空且唯一的 `qq_email` 列。已有数据、账号密码和项目关系不重置；应用表仍为13张，另有迁移管理表。

| 接口 | 权限和行为 |
| --- | --- |
| POST /api/auth/register | 本机匿名自助注册；仅允许用户名、密码、QQ邮箱，不能传全局角色或成员关系 |
| GET/PATCH /api/auth/me | 仅本人；更新显示名称及QQ邮箱 |
| PATCH /api/projects/{id} | 当前项目管理员，更新和成员变更使用既有项目锁串行化 |
| GET /api/projects/{id}/members | 当前项目任意成员，含成员联系邮箱；撤权后现有会话也不能读取 |
| GET /api/users?username=… | 仍仅项目管理员可精确搜索；输出基础身份，不返回QQ邮箱 |
| PUT/DELETE 项目成员 | 仍需当前项目管理员，保留最后一位管理员保护 |

邮箱由本人填写，当前**未验证邮箱归属**，不发送注册验证码、邀请或联系邮件。支持QQ数字地址及ASCII别名，限@qq.com域；唯一约束不证明邮箱真实存在。通讯录内邮箱只在本人资料与同项目成员列表响应中出现，不向全局用户名搜索开放。浏览器已经获取的联系人信息无法撤回，撤权限制后续读取。

当前为本机原型，没有邮箱验证、密码找回、更换登录用户名或面向公网的注册限流方案。原先“不提供注册/成员列表仅管理员可看”的描述属于历史范围，本批规则优先。

## 请用户实际操作

打开 http://127.0.0.1:5173 ，刷新后：

1. 登录页点击“还没有账号？注册账号”，用自己的中文用户名、QQ邮箱及密码注册；再用该用户名登录。
