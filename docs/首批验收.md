## 演示账号

账号密码保存在本机 `.local/demo_accounts.json`，请在编辑器中查看，不发到聊天或提交 Git。初始化工具重复运行不会重置已有密码或恢复已撤销成员关系。

| 用户名 | 初始权限 |
| --- | --- |
| demo_admin | 科研项目 A 的管理员 |
| demo_member | 科研项目 A 的普通成员 |
| demo_other | 独立项目 B 的管理员，不属于项目 A |

## 你的验收步骤

1. 使用 `demo_admin` 登录，确认只显示“科研项目 A”，可以查看成员和创建项目。
2. 尝试撤销自己在 A 的访问：若仍是唯一管理员，应收到不能撤销最后管理员的提示。
3. 退出后使用 `demo_member` 登录，确认可见 A，但没有成员管理表单。
4. 退出后使用 `demo_other` 登录，确认只显示 B。
5. 管理员在 A 中添加 `demo_other` 为普通成员；该账号重新登录应能看到 A 与 B。
6. 管理员撤销 `demo_other` 对 A 的权限；该账号刷新项目后 A 消失，B 仍保留。验收结束保留原始项目关系或记录所做变更。
7. 关闭或刷新页面后需要重新登录，这是令牌只保存在内存的预期行为。

反馈时写“步骤、账号、现象、期望”，错误页面的追踪编号可帮助定位，不提供密码和令牌。上述人工步骤目前仍为待验收，AI 浏览器检查不替代你的反馈。
